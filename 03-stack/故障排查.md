# 故障排查

> 按症状查。每条给：先跑什么 → 判据 → 修法。
> 顺序原则：**先确认是不是已知边界（`04-上手/02-已知限制.md`），再动手。**

---

## 1. H3 不在线 / 提交无响应

```bash
curl -s http://127.0.0.1:8188/system_stats
netstat -ano | findstr :8188
```

| 判据 | 含义 | 修法 |
|---|---|---|
| 连不上 | 进程没起或已崩 | 看实例日志尾巴；重启带全 flag |
| 连得上但队列不动 | 任务卡住/显存不足 | 查 `/queue`；必要时 `/api/free` |
| 端口被别的进程占 | 起错实例 | 停掉占用者，确认是 H3 |

**不要在任务正常采样时硬中断**——先看进度与 GPU 活动。

---

## 2. 跑批前被 preflight 中止

常见中止信息与对应：

| 信息 | 含义 | 修法 |
|---|---|---|
| 模板链型/分辨率 ≠ spec | 模板与配置不同步 | 重建模板：`build_twopass.py --shot <镜>` |
| 参考视频帧数 ≠ 24 | 尾段截取不合格 | 重截：`relay.py --shot <上镜>` |
| 模板含禁用节点 | 旧代模板残留 | 重建；检查 `forbidden_nodes` |
| 资产双份不一致 | 项目份改后没同步 | `sync_assets.py --sync` |
| 产物分辨率不符 | 输出的是旧档位 | 检查模板与 spec，不要改校验 |

**纪律**：preflight 中止 = 配置或派生链有问题，**不要通过改参数绕过**。

---

## 3. 提交返回 400 / value_not_in_list

| 原因 | 判据 | 修法 |
|---|---|---|
| 模板缺节点 | 日志里点名节点 | 恢复节点或重建模板 |
| 文件路径不在允许列表 | 参数是子目录/绝对路径 | 用节点支持的路径形式（例如换用 Path 变体） |
| 模型文件名不符 | 模板里的名字与实际文件不同 | 统一命名或改模板 |

---

## 4. 同一个镜头连续多张候选都锁不上（首帧差 50–70）

这是**设计矛盾**的典型，不是抽卡质量。

```bash
python code/quality_gate.py <产物.mp4> --ref <上镜尾帧.png>
```

| 追加判据 | 含义 |
|---|---|
| 人工版与自动版在同度量下都 ~50+ | 排除随机性 |
| 状态描述里有「切 / 平行 / 另一处」 | 跳变镜却锁了帧 |

**修法**：去掉锁帧与尾段参考，改为硬切；保留颜色/氛围的软延续。

**不要**：继续换种子抽卡。

---

## 5. 首帧对上了，但人物瞬移 / 手换位置 / 道具消失

| 原因 | 判据 | 修法 |
|---|---|---|
| 首帧描述漏项 | 对照尾帧图逐项看：姿态、手、道具、表情、背景 | 逐项补齐描述 |
| 按设计写而非按图写 | 图里是站定，文字写「滑行急停」 | 按实际内容重写开场 |
| 锁帧图不在首位 | 参考图列表顺序 | 尾帧图排第一 |

**规则**：换锁帧 = 三处同步（主体定义 / 场景继承 / 正文开场）。

---

## 6. 接缝卡顿或跳变

| 症状 | 先查 | 修法 |
|---|---|---|
| 动作不连续 | 下一镜是否带了尾段视频 | `relay.py --shot <上镜>` 后重新生成 |
| 首帧位移大 | 尾段帧数 / 是否重编码 | 24 帧、重编码 |
| 色调跳 | 两镜调色描述是否一致 | 统一调色串；交付版做颜色匹配 |
| 拼接处发糊 | 是否用淡化掩盖大错位 | 先修首帧，再淡化 |
| 总时长不对 | 是否用了乘法估算 | 逐镜实测累加 |

---

## 7. 音频削波 / 台词弱

```bash
python code/audio_check.py <产物.mp4>
```

| 判定 | 含义 | 修法 |
|---|---|---|
| `CLIP破音` | 峰值 > 0dB | 直接淘汰，削波不可逆 |
| `台词弱` | 台词窗 RMS < -30dB | 检查环境声描述；重抽或后期提亮 |
| 抽卡正常、二采变小 | 二采链路音频弱化 | 拼接时全片统一响度 |

**坑**：判定看 `peak` 列；若表里出现 `Peak count`，那是通道数，不是削波次数。

## 8. 内存/显存不够

| 症状 | 判据 | 修法 |
|---|---|---|
| 超分时系统卡死 | 一次载入全部帧 | 单镜层、分批、每批清缓存 |
| 长时批跑后崩溃 | 空闲内存持续下降到 <10GB | `/api/free`；仍不足则重启 H3 |
| 启动即 OOM | 分辨率/时长组合超限 | 降档位，不要硬撑 |

```bash
python -c "import psutil; print(psutil.virtual_memory().available/1e9)"
```

**禁止**：任务运行中同时开另一个实例或跑别的 GPU 任务。

---

## 9. 尾段花屏 / 最后几帧坏

| 条件 | 结论 |
|---|---|
| 镜头 >10 秒且带了 sage | 主因：关掉 sage 重跑 |
| 镜头 ≤10 秒仍出现 | 记录本次参数与种子；尝试裁掉坏尾帧（用前一正常帧） |
| 只在长序列出现 | 缩短镜长或拆分 |

---

## 10. 产物「看起来没更新」

| 原因 | 判据 | 修法 |
|---|---|---|
| 改稿没换种子 | 产物 mtime 早于 md mtime | 换新种子域重跑 |
| 缓存/同名 | 文件名同、内容旧 | 清对应产物或换命名 |
| 跑的是旧模板 | 模板 mtime / chain_check | 重建模板 |

```bash
python code/chain_check.py check --shot <镜> --md <md> --episodes magic/configs/episodes.json --template <模板>
```

---

## 11. 中文乱码 / 脚本崩溃

| 场景 | 原因 | 修法 |
|---|---|---|
| 控制台输出乱码 | GBK/UTF-8 混用 | 脚本里 `sys.stdout.reconfigure(encoding="utf-8")` |
| subprocess 抓输出丢字段 | 解码失败 | `text=True, encoding="utf-8", errors="replace"` |
| 批处理文件解析失败 | 中文写在特殊块内 | 改用 UTF-8 无 BOM，或避免在配置块内写中文 |

---

## 12. H3 读不到素材

| 原因 | 判据 | 修法 |
|---|---|---|
| 用了目录链接 | 路径存在但节点报错 | 改真实目录 + `sync_assets.py` |
| 同步漏文件 | `sync_assets.py --check` 有差异 | `--sync` |
| 文件名撞名 | 不同角色同名文件 | 角色前缀命名 |

## 13. 时长/规格对不上

```bash
ffprobe -v error -show_entries format=duration -of csv=p=0 <file>
ffprobe -v error -select_streams v:0 -show_entries stream=width,height,r_frame_rate -of csv=p=0 <file>
```

| 现象 | 原因 | 修法 |
|---|---|---|
| 成片比预期短 | 乘法估算 | 逐镜实测累加 |
| 单镜时长与请求差 2–4 帧 | 模板补帧到 17 的倍数 | 容差设 ≤5 帧（0.2s） |
| 分辨率差几像素 | 内部对齐到 32 | 以 spec 的档位为准，不要手补缩放 |

---

## 14. 排查时的三条纪律

1. **先找已知边界**：`04-上手/02-已知限制.md` 里有的，不要当 bug 修；
2. **同因失败 3 次就停**：继续抽卡只会更贵；
3. **一次只改一处**：改两处，结果变好也不知道是哪一处起的作用。
