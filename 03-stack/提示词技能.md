# 参考实现：提示词技能与检查器

> 绑定 2026-09 技术栈，会过时。关注结构，不要照抄内容。
> 检查链的设计见 `01-method/05-提示词检查链.md`；可直接改的骨架见 `templates/skill/`（含可跑的校验器）。

---

## 1. 技能包结构

```
.claude/skills/h3-prompt-writing/
├── SKILL.md                       # 规程（7 步）
├── references/
│   ├── base-en.txt                # 权威格式：文本/首尾帧模式
│   ├── ref-en.txt                 # 权威格式：多参考模式（六段式）
│   ├── spatial-rules.md           # 领域规则：空间与动作（含正例/反例；本包未附）
│   └── battle-library.md          # 领域规则：招式固定短语（单一事实源）
└── scripts/
    └── validate_h3_prompt.py      # 机械 + 语义 + 动作链校验
```

要点：
- **权威格式是文本文件**，不是模型记忆。每次生成都读。
- **领域规则独立成文**，技能只引用，不复制。战斗技能的唯一事实源在项目文档里，这里只放「可用短语」。
- 校验器可单独运行，不依赖 agent。

---

## 2. 规程七步

1. 识别模式（文生 / 图生 / 首尾帧 / 末帧 / 多参考）
2. 文本与关键帧模式 → 读 `base-en.txt`
3. 多参考模式 → 读 `ref-en.txt` 的六段式重写格式
4. 严格保留字段名、段序、标签与时序记法
5. 领域复核：动作镜读 `spatial-rules.md`，逐条对照正例/反例改写；招式短语只从规则库取，禁止自创
6. 强制校验：
   - `validate_h3_prompt.py <prompt.md> --duration <sec>`（机械 + 七律 + 语义 + 动作链）
   - `check_scene_chain.py <shot_id>`（场景继承：角色去向必须交代）
7. 交付报告：命中的规则 + 改写掉的反例 + 校验输出原文，供人过闸

**关键设计**：第 6 步是**强制**的，不是建议。第 7 步把人闸需要的证据一次性给全。

---

## 3. 机械校验覆盖什么

| 类别 | 内容 |
|---|---|
| 结构 | 六段齐全、段序正确、标签闭合 |
| 时长 | 时间戳单调、不超过镜头时长、末点接近结尾 |
| 语言 | 负面指令、精确米数、角色相对方位（无屏幕/景深限定）、摄影术语误用 |
| 预算 | 参考图数量上限、媒体引用上限、提示词长度上限 |
| 动作链 | 入画参照、落点、残余速度、远程目标、事件间隙 |
| 领域 | 近战禁用词表（如「杖」不得作为近战武器）、招式必须来自规则库 |

输出分级：`[ERROR]` 必须清零；`[WARN]` 逐条判断（部分规则只对特定镜型生效，例如「七律」警告对非对决镜可忽略）。

## 4. 语义与半自动检查

| 检查 | 方法 | 判定 |
|---|---|---|
| 锁帧语义 | 视觉模型看参考图，回答「人物是静止还是在动」「手是否握杖」等窄问题 | 近景矛盾 → 中止；远景 → 警告 |
| 构图尺度 | 纯文本：上游尾段最后一个尺度词 vs 下游复述句首尺度词 | 强对立 → 冲突 |
| 空间断言 | 正则提取机位/站位/路径断言 → 视觉模型逐条判 PASS/FAIL | 有 FAIL → 退出码 1 |

**一个可迁移的经验**：让视觉模型「自由找茬」召回率很低；改成**枚举断言 + 强制四选一**（存在/布局/方向/不在画面）后才有生产价值。我们的记录里，自由审查与断言式审查的差距极大，后者才被允许进入流程。

## 5. 检查器链的执行顺序

```
写稿
 ├─ validate_h3_prompt.py      # 结构 + 语言 + 预算 + 动作链
 ├─ check_scene_chain.py       # 跨镜一致性
 ├─ check_lockframe_desc.py    # 构图尺度（零 GPU）
 ├─ check_ref_desc.py          # 锁帧语义（视觉模型）
 └─ prompt_review.py           # 空间断言（视觉模型）
        ↓
      人闸 G2
```

顺序的理由：前三个零成本先跑；视觉模型的两个放后面，且只作警告。

## 6. 分发注意

如果要把它做成对外模板：

1. **删掉内部路径**与项目专属命名；
2. **抽取领域规则**：战斗技能表属于具体作品，不应进入通用包；
3. **保留结构**：七步流程、四类检查、ERROR/WARN 分级；
4. **补回归样本**：至少 3 份好稿 + 每类 1 份坏稿，否则别人改完规则不知道有没有退化。

## 7. 这版的经验值

| 项 | 值 |
|---|---|
| 六段式正文长度 | 350–500 词 |
| 提示词长度上限 | 约 7000 字符 |
| 参考图上限 | 5 张（多人镜实际只用 2–3 张锚定） |
| 音轨上限 | 3 条 |
| 校验失败的处理 | ERROR 一律中止；WARN 由人判断 |
| 最常触发的检查 | 负面指令、时间戳超时长、锁帧描述漏项 |
