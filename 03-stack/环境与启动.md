# 环境与启动

> 基线：Windows 11 · RTX 4060 Ti 16GB · 2026-09。
> 路径用占位符：`<AISV_ROOT>` 项目根、`<ComfyUI_H3>` 视频实例、`<ComfyUI_ASSETS>` 资产实例。

---

> **平台**：脚本使用 PowerShell / netstat / Windows 路径，目前仅支持 Windows。

## 1. 两个实例，二选一

| 实例 | 端口 | 用途 | 常驻内容 |
|---|---|---|---|
| H3 | 8188 | 视频生成（Ref2VA 模板） | UNet / Video VAE / Audio VAE / Qwen3-VL 文本编码器 |
| 资产 | 8189 | 文生图、多视角、视觉模型审图 | FLUX / 图像编辑 / 4B 级 VLM |

**铁律：同一时间只跑一个。**
每个工作流会占掉大部分显存；双开实测会导致系统卡死、丢任务。

```bash
# 谁在占端口
netstat -ano | findstr :8188
netstat -ano | findstr :8189

# 停进程（Windows）
powershell -Command "Stop-Process -Id <PID>"
```

停止前先确认 PID 是哪个实例——别按名字杀一堆 python。

## 2. H3 启动

```bash
<ComfyUI_H3>\python_embeded\python.exe -s <ComfyUI_H3>\ComfyUI\main.py \
  --port 8188 --listen 127.0.0.1 \
  --disable-pinned-memory --cache-ram 16
```

| 参数 | 为什么 |
|---|---|
| `--disable-pinned-memory` | 避免长时间运行内存只增不减 |
| `--cache-ram 16` | 限制内存缓存；本机 32GB，留余量 |
| `--use-sage-attention` | **仅 ≤10 秒镜**。>10 秒会出现尾段花屏（实测 12 次） |

启动后自检：

```bash
curl -s http://127.0.0.1:8188/system_stats
```

**期望**：返回 JSON，包含设备与显存信息。

## 3. 资产实例启动

```bash
<ComfyUI_ASSETS>\python_embeded\python.exe -s <ComfyUI_ASSETS>\ComfyUI\main.py \
  --port 8189 --listen 127.0.0.1 \
  --disable-pinned-memory --cache-ram 16
```

资产侧做三件事：

1. 角色多视角（同一角色不同角度必须来自同一条流程）；
2. 场景图；
3. 视觉模型审图（锁帧语义、空间断言）。

## 4. 目录约定

```
<AISV_ROOT>/
├── code/                     # 随包脚本
├── magic/                    # 子项目（示例）
│   ├── docs/prompts/         # 镜头源文档（唯一事实源）
│   ├── assets/               # 项目份资产
│   ├── configs/              # episodes / 批次 / 状态
│   ├── output/               # 产物（不入库）
│   └── preview/              # 审片帧（不入库）
└── test/                     # 一次性实验（可删）

<ComfyUI_H3>/ComfyUI/input/magic/assets/    # H3 份资产（副本）
<ComfyUI_H3>/ComfyUI/output/magic/          # 生成产物
```

**资产必须两份**：H3 不接受目录链接（junction），只读自己 input 下的真实目录。
改项目份后必须 `python code/sync_assets.py --sync`。

## 5. 模型与节点

| 角色 | 类型 | 备注 |
|---|---|---|
| UNet | Ref2VA，int8 | 视频生成主模型 |
| LoRA | Turbo 4-step | 低步数出片，配合 4 步采样 |
| 文本编码器 | Qwen3-VL 量化版 | 提示词理解 |
| VAE | Video / Audio 各一份 | 音视频解码 |
| 放大 | 2× 保守模型 | 逐帧超分 |

**节点依赖**：模板用到 `ResolutionSelector / ManualSigmas / SplitSigmas / LoraLoaderModelOnly / MiniMaxH3*` 等。
删包或升级自定义节点前，先跑一遍模板加载自检——缺节点会在提交时表现为 400。

---

## 6. 冻结纪律（重要）

当前环境是**验证可用**的状态。以下操作视为破坏性，必须先记录再执行：

| 操作 | 风险 |
|---|---|
| `git pull`（ComfyUI 本体） | core API 变动，1164 个模板可能失效 |
| `pip install` / 升级包 | 加速库版本与内核不匹配，出花屏或崩溃 |
| 增删自定义节点 | 模板缺节点 → 提交 400 |
| 改模型目录 | 模板里的路径失效 |

流程：记录当前 commit/包版本 → 变更 → 跑冒烟清单（单镜 5 秒能出片）→ 不能出则回滚。

## 7. 启动检查清单

```
□ 只开一个实例（8188 或 8189）
□ H3 带 --disable-pinned-memory --cache-ram 16
□ >10 秒镜不带 sage；≤10 秒**必须**带（runner 校验）
□ 空闲内存 ≥10GB（低于则先释放）
□ python code/run_twopass_auto.py --status 全绿
□ python code/sync_assets.py --check 无差异
```

## 8. 资源守护

长时批跑前：

```bash
# 空闲内存
python -c "import psutil; print(psutil.virtual_memory().available/1e9)"
```

| 阈值 | 动作 |
|---|---|
| < 10 GB | 触发 `/api/free`；仍不足则重启 H3 |
| 连续多镜后持续下降 | 视为泄漏迹象，人工重启 |

**不要**在任务运行中同时跑其他 GPU 任务（包括另一个实例、超分、训练）。
