# 验收清单：什么算「跑通了」

> 落地层第 5 篇。这一篇是**尺子**。
> 适配器写完不算数，方法读懂不算数——**12 项全过，且每项的输出都贴得出来**，才算接上了。

---

## 0. 使用方式

### 三级验收

| 级别 | 何时跑 | 项 | 不通过的处置 |
|---|---|---|---|
| **A 契约级** | 适配器写完时，一次性 | A1–A6 | 改适配器，不改文档 |
| **B 镜头级** | 每个镜头完成后 | B1–B3 | 改这一镜或重抽 |
| **C 全片级** | 拼接与交付后 | C1–C3 | 回到对应镜修 |

### 判据形式

每一项都必须给出**命令**与**期望值**。不接受「我看过了」「应该没问题」。

验收单要留存输出原文——三个月后回来看，能知道当时是真的过了，还是放过了。

### 命令约定

下面的命令用两个占位符：

- `<adapter>`：你的适配器模块（实现 `02-适配器契约.md` 的六个函数）；
- `<spec>`：你的配置文件路径。

如果你的实现不是 Python，把命令换成等价形式即可，**期望值不变**。

## A. 契约级（一次性，6 项）

### A1 生成产物存在且规格正确

```bash
python -c "import json,adapter; print(json.dumps(adapter.measure('<out>/a.mp4'), default=str))"
```

| 项 | 期望 |
|---|---|
| 文件存在 | 是（非空，可解码） |
| 宽高 | == 请求值（±2px） |
| 帧率 | == 请求值（±0.01） |
| 时长 | 与请求值差 < 0.05s，**且是实测值** |
| 音轨 | 与能力声明一致 |

**不通过的常见原因**：返回了缓存/旧文件；把请求参数原样抄进返回值；分辨率被内部对齐到 32 的倍数但未回写。

### A2 返回的时长是实测，不是抄的

```bash
python -c "import adapter; r=adapter.generate(req); print(r['duration_sec'], adapter.measure(r['video_path'])['duration_sec'])"
```

**期望**：两个数之差 < 0.05s。

**为什么单独列**：这是最容易作弊的一处。如果适配器把请求值抄回来，后面所有「时长校验」都变成自证。

### A3 尾段截取：帧数精确 + 重编码

```bash
python -c "import adapter; t=adapter.extract_tail('a.mp4', 24); print(t['frame_count'], t['video_path'], t['image_path'])"
ffprobe -v error -count_frames -select_streams v:0 -show_entries stream=nb_read_frames -of csv=p=0 <tail.mp4>
```

| 期望 | 说明 |
|---|---|
| 返回 `frame_count` == 24 | 精确，不是「约」 |
| ffprobe 计数 == 24 | 说明返回值和文件一致 |
| 尾帧图来自同一段 | 图 = 尾段最后一帧 |

**重编码验证**：截取命令里不应出现流拷贝（copy）选项；若不确定，比较截取首帧与源视频对应帧的差异，流拷贝常表现为开头黑帧/坏帧。

### A4 像素差度量有区分度

```bash
python -c "import adapter; print(adapter.compare_frames('a.png','a.png'), adapter.compare_frames('a.png','b.png'))"
```

**期望**：第一个 == 0；第二个 > 0（且与肉眼差异同量级）。

**不通过的含义**：门禁形同虚设。若两条都返回 0，或都返回同一个常数，检查是否只比较了尺寸/哈希，而没有比较像素。

### A5 拼接：逐镜实测累加

```bash
python -c "import adapter; r=adapter.join_clips(['a.mp4','b.mp4'], 0.2, 0.2); print(r['durations'], r['total_sec'], r['offsets'])"
```

**期望**：`total_sec ≈ durations[0] + durations[1] - 0.2`（±0.15s），且 `durations` 是实测值。

**不通过的常见原因**：用了「镜数 × 单镜时长」；把交叉淡化算成加法而不是减法；输入规格不一致却静默缩放。

### A6 产物 sidecar 完整

```bash
python -c "import json; print(json.load(open('<out>/a.mp4.json')))"
```

**必须含**：`spec_revision`、`stack.name/version`、`shot`、`mode`、`seed`、`prompt_sha256`、`refs`、`requested`、`actual`、`created_at`。

**期望**：`actual` 与 `measure` 的结果一致。

**为什么**：三个月后要回答「这是哪版生成的」。没有 sidecar，只能靠猜。

## B. 镜头级（每镜，3 项）

### B1 锁帧：首帧像素差

```bash
# 从产物中取出第一帧，与上一镜尾帧图比较
python -c "import adapter; print(adapter.compare_frames('<first_frame>.png','<prev_tail>.png'))"
```

| 值 | 判定 |
|---|---|
| < 15 | 优 |
| 15–25 | 及格 |
| 25–50 | 需重抽或检查描述 |
| ≥ 50 | 基本是设计矛盾或走样，先查设计 |

**注意**：这是必要条件，不是充分条件。像素差小但人物数量/朝向/动作不对，照样是废片。

**锁帧镜还必须满足**：尾帧图在参考图列表首位；首帧描述逐项命名了图中内容（姿态、手、道具、背景）。

### B2 运动延续：A/B 对照

同一提示词、同一首帧图，跑两条：

| 组 | 条件 |
|---|---|
| A | 不带尾段视频 |
| B | 带 `tail_frames` 帧尾段视频 |

**期望**：B 组的首帧位移（与 A 组同度量比较）明显下降。

没有下降 = 参考视频没生效——先查帧数是否太少、是否用了流拷贝、是否模型根本不支持。

**注意**：这条只在能力清单里 `supports_ref_video: true` 时适用；不支持就跳过并在验收单注明「已降级」。

### B3 音频峰值

```bash
ffmpeg -nostats -i a.mp4 -af astats=metadata=1:reset=0 -f null - 2>&1 | grep -i "Peak level"
```

**期望**：峰值 ≤ 0 dB（spec 的 `audio_peak_max_db`）。

**不通过**：直接淘汰该候选，不要试图「修复」——削波不可逆。

**坑**：某些工具输出的 `Peak count` 是**通道数**，不是削波次数。别拿它当判据。

## C. 全片级（3 项）

### C1 总时长 = 逐镜实测累加

```bash
python -c "import adapter,json; r=adapter.measure('<final>.mp4'); print(r['duration_sec'])"
# 与 join 报告里的 total_sec 比较
```

**期望**：两者差 < 0.2s；并且 `total_sec` 由每个输入的实际时长累加得出。

**不通过**：回到 `join_clips` 检查累加公式。

### C2 规格统一 + 三层版本

| 检查 | 期望 |
|---|---|
| 分辨率 | 全片统一，== `deliver` 配置 |
| 帧率 | 统一 |
| 音轨 | 存在且采样率统一 |
| 响度 | 全片统一（如 -16 LUFS），无削波 |
| 审片版 | 硬切，无淡化 |
| 标注版 | 每镜有编号小标 |
| 交付版 | 淡化 + 色彩匹配 + 统一响度 |

**为什么审片版不能带淡化**：淡化会把接缝盖住，审片时看不见问题。

### C3 复现性

同一个 spec、同一个种子，再跑一次：

| 能力 | 期望 |
|---|---|
| 可复现 | 两次产物在允许容差内一致（或至少度量一致） |
| 不可复现 | 记录本次偏差；后续所有对照实验改为多次采样比较 |

**不通过也不一定是缺陷**——很多模型就是不可复现。关键是**知道**这一点，并在做 A/B 时用对方法。

## 12 项总表（可勾选）

```
□ A1 产物存在且规格正确
□ A2 返回时长是实测
□ A3 尾段帧数精确 + 重编码
□ A4 像素差度量有区分度
□ A5 拼接逐镜累加
□ A6 sidecar 完整
□ B1 锁帧像素差 < 25（衔接镜）
□ B2 运动延续 A/B 有改善（如支持）
□ B3 音频峰值 ≤ 0 dB
□ C1 全片时长 == 逐镜累加
□ C2 规格统一 + 三层版本
□ C3 复现性已确认并记录
```

## 最后一条

> **验收失败时，改适配器，不要改判据。**

判据是从真实事故里来的，改一次就少一道防线。
如果确实要调阈值，写清楚：为什么调、用什么样本标定的、调完回归结果如何。
