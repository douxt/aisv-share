# AI 短剧生产线 — H3 实战包

> 用 MiniMax H3（ComfyUI）+ 消费级显卡，做完了 25 镜 / 6 幕 / 4 分 11 秒的成片。
> 这里是从立项到交付的完整方法、实测数据（粗估处已标注），以及能直接照着跑的流程。

---

## 适用范围（先读这段）

| 你用的栈 | 本包对你的价值 |
|---|---|
| **H3 + ComfyUI（同款或相近）** | 全包可用：方法 + 命令 + 配置 + 踩坑 |
| 其他视频模型 | 只有 `01-method/` 有参考价值；命令、配置、脚本都不适用 |
| 纯代码/其他框架 | 同上，且不建议照搬 |

本包**不提供跨模型适配指南**。原因：适配层的成本远高于收益，而且换模型后大部分经验要重测。
如果你之后换栈，`archive/generic/` 里有一版通用骨架可以当底稿（不维护）。

**环境基线**：Windows 11 · RTX 4060 Ti 16GB · ComfyUI 双实例（H3 8188 / 资产 8189）· 2026-09 配置。
**平台限制**：脚本使用 PowerShell / netstat / Windows 路径，目前仅支持 Windows。

## 包里没有什么

- **模型权重、LoRA、放大模型**：各有权重许可，不二次分发。
- **角色资产图与音色文件**：涉及素材授权，不随包分发。
- **个人信息与凭证**：不含用户名、密码、密钥；文档中的安装路径（如 `C:/AI/ComfyUI_H3`）只是示例，可改。
- **可视模型检查器等可选件**：`check_ref_desc` / `vlm_desc` / 全自动编排未随包。
- **跨模型适配指南**：见「适用范围」。

## 时效

> 技术会过时，方法不会。

- `01-method/`：结论来自实测，但比例数字（拍数、阈值）绑定 24fps 与 10–15 秒镜；
- `03-stack/`、`04-上手/`：写死 2026-09 的脚本与参数。半年内大概率需要重核；
- 每篇开头有基线日期。遇到冲突，以你自己的实测为准。

我们对「外部结论」的态度也写进了方法层：**社区或论文的结论，在你本机验证前只是假设。**

## 术语

| 词 | 含义 |
|---|---|
| 镜 / shot | 一次生成的最小单位，通常 5–15 秒 |
| 拍 | 镜内的一个可观察状态变化（0.5s 唱第一句 / 2s 切近景） |
| 抽卡 | 同一提示词换种子批量生成多份，供挑选 |
| 二采 | 对选中的片子做高分辨率二次生成 |
| 锁帧 | 把上一镜尾帧作为本镜首帧 |
| 接力 | 截取上一镜的尾帧图 + 尾段视频，作为下一镜输入 |
| 接缝 | 两个镜头拼接处 |
| 门禁 | 自动检查点，不通过就中止 |
| 六段式 | 我们的提示词结构：主体定义 / 摘要 / 保留分析 / 详细描述 / 环境声 / 配乐 |
