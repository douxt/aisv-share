# 分镜表（模板）

> 一行一镜。**拍数是独立列**——否则无法自动校验「拍数 ≤ 时长允许上限」。
> 字段可裁剪，但这几列不要删。

| 幕 | 镜号 | 时长 | 拍数 | 内容摘要 | 说话者 + 台词 | 参考图 | 承接 | 状态 |
|---|---|---|---|---|---|---|---|---|
| 1 | 1a | 10s | 3 | 主角独唱开场，缓慢推近 | 主角：「……」 | hero, stage | 硬接上一镜尾帧 | 待写 |
| 1 | 1b | 5s | 1 | 转身看向台侧 | — | 1a 尾帧, hero, stage | 硬接 | 待写 |
| 1 | 1c | 10s | 2 | 台侧人物入画 | 配角：「……」 | hero, rival, stage | 软接（文戏） | 待写 |

## 字段说明

| 列 | 含义 | 约束 |
|---|---|---|
| 幕 | 叙事单元 | 每幕 3–5 镜 |
| 镜号 | 唯一标识，用于文件名与依赖 | 一经使用不重命名 |
| 时长 | 生成秒数 | 主力 10s；5s 用于单动作；15s 只用于低密度 |
| **拍数** | 可观察的状态变化次数 | 5s ≤2；10s ≤4；15s ≤5（每拍 ≥0.8s） |
| 内容摘要 | 一句话：谁做了什么 | 一镜一个主导事件 |
| 说话者 + 台词 | 按发声顺序编号 | 一镜一说话者；多说话者按时间戳错开 |
| 参考图 | 用的资产（逗号分隔） | ≤ 模型上限；衔接镜的首帧图排第一 |
| 承接 | 硬接 / 软接 / 独立 | 硬接 = 首帧锁定上一镜尾帧 |
| 状态 | 待写 / 已写 / 已生成 / 已验收 | 只增不改 |

## 配套的每镜记录（放提示词文件里，不放这张表）

```yaml
shot: 1b
version: 3
seed_range: [10010, 10013]
chosen_seed: 10012
refine_seed: 20007
first_frame_diff: 12.4
audio_peak_db: -1.8
notes:
  - v1 动作太急 → 拉长到 10s？否，改为减少一拍
  - v2 结尾悬空 → 补 settle 句
  - v3 采用
```

**为什么记录要留**：三轮迭代后，你只剩文件名和一堆视频；没有记录就分不清哪版改了什么。
